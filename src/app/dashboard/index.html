About these readings

The system estimate uses the larger of the system sensor reading and the CPU + GPU + ANE subtotal; it is not wall-socket power. DRAM and GPU SRAM are separate reported values and should not be added to these totals. Some unsupported counters report zero, so zero alone does not establish zero consumption. Missing and virtual-machine readings stay unavailable.
