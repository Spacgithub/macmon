# Terminal controls for the browser dashboard

## Behavior and decisions

- `macmon web` starts the managed background service and opens the dashboard once ready.
- `macmon web start` starts monitoring without opening a browser; repeated starts reuse it.
- `macmon web stop` unloads the managed job, ending its sampling and releasing its port.
- `macmon web status` reports service state and the dashboard address without starting it.
- Expose these commands through `macmon -h`, `macmon web -h` and individual command help.
- Reuse the existing embedded desktop controller, including exact job ownership checks,
  loopback defaults and compatible login agents. Closing a tab leaves monitoring running.
- Keep the TUI, metric formats, library API, configuration and existing service unchanged.
  Add no dependencies; develop and verify in an isolated worktree without restarting the
  user's current backend.
